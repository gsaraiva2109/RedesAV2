# Simulador de FSMs - TCP & UDP

Simulador com interface gráfica e execução desacoplada para modelar, visualizar e testar as Máquinas de Estados Finitos (FSMs) dos protocolos TCP e UDP sobre um canal configurável com ruído e perdas.

Trabalho prático da disciplina de **Redes Convergentes (AV2 - UNIFOR)**.

## Tecnologias

- **Linguagem:** TypeScript
- **Frontend:** React, Vite, Tailwind CSS
- **Testes:** Vitest

## Como Executar

### 1. Instalação
```bash
npm install
```

### 2. Interface Gráfica
```bash
npm run dev
```
Acesse no navegador: `http://localhost:5173`

### 3. Testes Automatizados (10 Cenários)
```bash
npm test
```
